# Felipe Alexandre

Desenvolvedor autodidata. Construo sistemas em Python e TypeScript trabalhando com agentes de IA (Claude Code e outros): eu defino os requisitos e as regras de risco, reviso o que a IA produz e exijo testes e evidência antes de aceitar uma mudança. Fundador da **Nexus Tech**.

## Como trabalho
- Faço varredura de segredos (gitleaks e revisão manual) antes de publicar qualquer repositório.
- Cada mudança relevante vem com teste e registro do que foi medido e do que não foi verificado.
- Uso IA abertamente; os commits trazem `Co-Authored-By`.

> Os projetos de trading não demonstram lucro nos backtests que fiz. O valor é de engenharia (risco, testes, rastreabilidade). Não é recomendação financeira.
